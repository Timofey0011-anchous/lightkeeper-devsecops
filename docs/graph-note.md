# Происхождение графа

`git-graph.png` построен из хешей и родителей настоящих коммитов Git.
Стрелка направлена от родителя к потомку; время идёт сверху вниз.
Граф содержит историю до коммита добавления самого изображения.
Это локальная схема, а не скриншот GitHub Network.
После публикации актуальный граф всех веток доступен через Insights → Network.
