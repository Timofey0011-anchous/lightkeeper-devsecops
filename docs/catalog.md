# Каталог оборудования

Файл `data/equipment.csv` содержит три вымышленные записи для проектирования.
Кодировка — UTF-8, разделитель — запятая, первая строка — заголовок.
Пустая ёмкость фонаря при импорте должна преобразовываться в `null`.
Эти данные не связаны с реальными устройствами пользователя.

## Состояния оборудования

| Значение | Значение для пользователя |
| --- | --- |
| `ready` | Пользователь отметил оборудование как готовое |
| `needs_service` | Требуется проверка или обслуживание |
| `retired` | Оборудование выведено из эксплуатации |

Фильтр по `status` позволяет быстро получить список на обслуживание.
